# Java Completo - Exercícios e anotações

Este repositório reúne exercícios, aulas práticas e anotações feitas durante o curso "Java COMPLETO Programação Orientada a Objetos + Projetos".

## Objetivo

- praticar fundamentos da linguagem Java;
- reforçar programação orientada a objetos;
- explorar coleções, herança, interfaces, generics, streams, arquivos e tratamento de exceções;
- desenvolver pequenos projetos e exercícios ao longo da formação.

## Estrutura do projeto

- `src/aulas/`: conteúdos por tema e exercícios de aprendizagem.
- `src/model/`: entidades, enums, serviços, exceções e modelos de domínio.
- `src/util/`: classes utilitárias e auxiliares.

## Como executar

1. Abra o projeto em uma IDE Java (ex.: IntelliJ IDEA).
2. Certifique-se de ter um JDK instalado e configurado.
3. Navegue até a classe `main` desejada e execute-a.

## Conteúdos principais

- Java básico e estruturas de controle
- Orientação a objetos
- Herança, polimorfismo e abstração
- Coleções (`List`, `Set`, `Map`)
- Arrays e matrizes
- Tratamento de exceções
- Interfaces, enums e generics
- Data e hora
- Streams e expressões lambda
- Arquivos e manipulação de arquivos
- Exercícios práticos e projetos menores

## Observação

Este projeto é um caderno de estudo pessoal, então a organização pode variar conforme os exercícios e conceitos aprendidos ao longo do curso.
